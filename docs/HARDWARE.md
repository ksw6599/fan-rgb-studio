# 하드웨어 지원과 문제 해결

## 실물 검증한 구성

| 대상 | 확인한 모델·동작 |
|---|---|
| 메인보드 | ASRock B650M PG Lightning / Nuvoton NCT6799D 채널 제어 |
| CPU | AMD Ryzen 5 9600X 온도·사용률 |
| GPU | MSI RTX 4070 Gaming X Trio 팬 센서 및 RGB |
| 쿨러 | Thermalright PA120 DIGITAL 온도·사용률 숫자 지속 전송 |

지원 범위는 LibreHardwareMonitor와 OpenRGB가 인식하는 하드웨어에 따라 다릅니다. 다른 모델·BIOS·연결 방식의 성공은 확인되지 않았습니다.

## 팬 목록이 비거나 GPU만 보임

1. 창 위에 **관리자 권한**으로 표시되는지 확인합니다.
2. PawnIO 설치 상태를 확인합니다. ZIP에 설치 파일이 있어도 드라이버가 자동 설치되지는 않습니다.
3. 드라이버 설치 후 트레이에서 **완전히 종료**하고 관리자 권한으로 다시 실행합니다.
4. 메인보드 모델, CPU 모델, 팬 목록 아래 안내 문구를 확인합니다.

보드 제어칩이 지원되지 않으면 권한이나 재실행만으로 해결되지 않습니다. 보드 모델과 진단 정보로 지원 여부를 확인해야 합니다.

## 채널 수와 실제 팬 수가 다름

앱은 **제어 채널**을 표시합니다. 빈 헤더가 나타날 수 있고 분배기·허브의 여러 팬이 한 채널로 보일 수 있습니다. 0 RPM은 정지·미연결·회전수 신호 부재 등을 구분하지 못할 수 있습니다. RGB 전선과 팬 모터 전원·PWM 전선은 별개입니다.

현재 팬을 잠시 가속해 위치를 찾거나 최소 회전 출력을 자동 보정하는 기능은 없습니다. 센서 이름만으로 펌프를 구분하지 않습니다.

## 팬 제어가 시작되지 않음

유효한 CPU 온도가 필요합니다. CPU 온도가 없을 때 GPU 온도만으로 제어를 시작하지 않습니다. 온도 신호·장치가 사라지거나 UI heartbeat가 끊기면 앱 소유 채널에 기본 제어 복원을 요청합니다.

## RGB와 숫자 표시

- RGB는 **RGB 연결**로 별도 감지합니다. 팬 속도와 RGB 감지 결과는 다를 수 있습니다.
- 색상·효과가 적용되지 않거나 멈추면 [RGB 문제 해결과 진단 저장](RGB.md)을 확인합니다.
- ASRock USB 메인보드의 구역별 단색은 Static 모드를 사용합니다.
- GPU RGB는 로그인 후 앱·장치 초기화가 완료되면 저장 설정을 복원합니다.
- PA120 표시는 TRCC와 동시에 연결하지 않습니다. 다른 쿨러 모델의 LCD 이미지·영상은 지원하지 않습니다.

이슈에는 버전, 모델, 관리자/PawnIO 상태, 화면 문구를 적어 주세요. 개인 경로와 전체 USB 식별자를 공개하지 않아도 초기 진단이 가능합니다.
