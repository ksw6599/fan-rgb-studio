# 처음 사용하는 분

## 준비와 실행

Windows 10/11 x64용입니다. 실물 검증은 Windows 11에서 수행했습니다. [.NET 8 Windows Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)가 필요합니다. 일반 .NET Runtime 대신 **Desktop Runtime**을 선택합니다.

1. [최신 릴리스](https://github.com/ksw6599/fan-rgb-studio/releases/latest)에서 **FanRgbStudio-win-x64.zip**을 받습니다.
2. ZIP 전체를 고정 폴더에 풉니다. EXE만 옮기면 필요한 DLL과 RGB 엔진을 찾지 못합니다.
3. `FanRgbStudio.exe` 우클릭 → **관리자 권한으로 실행**.
4. PawnIO가 미설치로 표시되면 왼쪽 **센서 드라이버 설치**로 포함된 공식 설치 프로그램을 실행합니다.
5. 설치 후 트레이 팬 아이콘 우클릭 → **완전히 종료**하고 관리자 권한으로 다시 실행합니다. 창의 X는 창만 숨깁니다.

## 팬 속도

자동 감지한 제어 채널은 팬 속도 영역 위쪽에 표시됩니다. 목록 안을 스크롤하면 나머지 채널이 보입니다.

1. 제어할 채널을 체크합니다. 펌프 채널은 선택하지 마세요.
2. **저소음 / 균형 / 성능 / 수동 / 사용자 곡선** 중 선택합니다.
3. 사용자 곡선은 온도(°C)와 출력(%)을 편집하고 지점을 추가·삭제합니다.
4. **팬 설정 적용**을 누릅니다. 채널별 설정은 자동 저장됩니다.

CPU·GPU 최고 온도를 사용하며 85°C 이상은 최대 출력입니다. 실제 출력은 PWM 해상도의 영향을 받습니다. `Fan #1`이라는 이름만으로 CPU 팬인지 케이스 팬인지 확정할 수 없습니다. 현재 물리 팬 식별·최소 출력 자동 보정·재검색 버튼은 없습니다.

**기본 제어 복원**은 앱 소유 채널을 기본 제어로 돌리고 저장된 팬 정책도 지웁니다.

## 조명과 숫자 화면

- **RGB 연결** → 장치·구역·효과·색상·밝기 선택 → **조명 설정 적용**.
- 메인보드 팬 조명은 ARGB 헤더, 보드 자체 조명은 PCB 구역입니다. GPU는 별도 장치로 선택합니다.
- 적용한 장치별 조명은 자동 저장되며 다음 실행에 다시 전송합니다. 부팅 직후에는 기본 색이 잠시 보일 수 있습니다.
- PA120 DIGITAL은 기존 TRCC를 트레이까지 종료한 뒤 **디스플레이 연결**을 누릅니다. 일반 LCD 이미지·영상은 지원하지 않습니다.

## 백그라운드와 로그인 시작

X / 최소화는 트레이로 숨기며 제어를 계속합니다. 완전히 끄려면 트레이 메뉴를 사용합니다.

선택적으로 `tools/Enable-Autostart.ps1`을 PowerShell로 실행하고 관리자 승인을 하면, 현재 EXE를 로그인 15초 뒤 관리자 권한으로 실행하는 작업에 등록합니다. 폴더를 옮겼다면 다시 등록합니다. 압축 해제만으로 시작 작업이 등록되지는 않습니다.

## 팬이 안 보이면

[하드웨어 지원과 문제 해결](HARDWARE.md)을 확인하세요. 한 PC에서의 성공이 모든 메인보드의 지원을 뜻하지는 않습니다.
