이 프로그램은 실제 팬 센서와 지원되는 RGB 제어기를 연결하는 Windows 앱입니다. 팬 설정은 처음 적용한 뒤 자동 저장되며 앱 재실행 시 복원됩니다. RGB 색상 변경은 적용 버튼을 누르세요. 적용한 장치별 조명 설정도 자동 저장하며 로그인 후 다시 전송합니다. 바탕화면 바로가기는 쿨러 숫자 화면과 RGB 엔진에 자동 연결합니다. TRCC가 실행 중이면 숫자 화면 연결을 막아 중복 전송을 피합니다.

시스템 팬 조명 바꾸기

  1. 트레이의 팬 아이콘을 더블클릭해 설정창을 엽니다.
  2. RGB 조명 영역의 시스템 팬 조명 선택을 누릅니다. 장치가 시스템 팬 / 메인보드 · ASRock B650M PG Lightning, 구역이 시스템 팬 · ARGB 헤더 전체로 선택됩니다.
  3. 색상·밝기를 고른 뒤 조명 설정 적용을 누릅니다. 한 구역만 바꾸려면 ARGB 헤더1/2/3 중 해당 구역을 고릅니다. 연결된 팬이 어느 헤더인지 모르면 ARGB 헤더 전체로 시작하세요.
  4. 그래픽카드 조명을 바꿀 때는 장치 목록에서 MSI RTX4070을 선택합니다. 쿨러의 숫자 색상은 아래 디스플레이 설정에서 따로 정합니다.

LED 수는 컨트롤러에 설정된 길이이며 실제 팬 개수가 아닙니다. 단색 구역을 나누어 색을 지정할 수 있지만, 무지개 등 장치 자체 효과는 장치 전체에 적용됩니다. 이런 효과를 선택하면 구역이 자동으로 장치 전체가 됩니다.

이번 PC에서는 메인보드 RGB USB의 상위 허브 오류43을 복구한 뒤, 사용자가 시스템 팬만 색이 바뀌는 것을 확인했습니다. Windows에서 RGB USB 연결이 끊기면 프로그램에서도 감지할 수 없으므로 단순 목록 누락과 USB 장치 오류를 구분해야 합니다.

창을 닫아도 계속 작동해요

바탕화면 선웅 Fan Studio를 실행하고 관리자 승인 창에서 예를 누르면, 설정창 없이 백그라운드에서 시작합니다. 작업 표시줄 오른쪽에 민트색 팬 아이콘이 생깁니다. 보이지 않으면 숨겨진 아이콘(∧)을 눌러 주세요.

  • 설정 열기: 팬 아이콘 더블클릭 또는 우클릭 → 설정 열기. 바탕화면 바로가기를 다시 실행해도 기존 창이 열립니다.
  • 창의 X / 최소화: 창만 숨깁니다. 센서·적용 중인 팬 제어·RGB·쿨러 숫자 전송은 계속 작동합니다.
  • 완전히 종료: 트레이 팬 아이콘 우클릭 → 완전히 종료. 이때 팬 기본 제어를 복원하고 디스플레이 연결과 소유한 RGB 엔진을 정리합니다.

백그라운드로 보내기는 프로그램 종료와 다릅니다. 설정창 왼쪽에도 백그라운드로 보내기 버튼이 있습니다.

v1.1.1 디스플레이 수정

연결 초기화와 PA120 모델 응답 확인, 입력 응답 읽기, 100ms 간격의 지속 전송을 추가했습니다. 센서 수치는 약 1초마다 갱신하며 화면 숫자와 미리보기 모두 소수점을 버립니다. 실제로 종료하면 표시가 사라지거나 마지막 값에 머물 수 있습니다. 다시 TRCC로 제어하려면 TRCC로 돌아가기를 누르세요.

새 기능: PA120 DIGITAL 숫자 화면

  1. TRCC를 종료합니다. 창을 닫아도 실행 중이면 작업 표시줄 오른쪽 TRCC 아이콘을 우클릭해 Exit/종료를 선택하세요. 두 프로그램이 동시에 USB 데이터를 보내면 화면이 깨질 수 있어 연결을 차단합니다.
  2. 이 앱을 관리자로 다시 열기로 실행하고 아래로 스크롤해 03 쿨러 숫자 디스플레이를 찾습니다.
  3. 표시할 CPU 온도·CPU 사용률·GPU 온도·GPU 사용률을 체크합니다. 단색 또는 온도에 따른 색상, 밝기를 고릅니다.
  4. 디스플레이 연결을 누르면 실제 PA120 화면으로 1초마다 전송합니다. 항목·색상·밝기는 연결 중에도 변경할 수 있습니다. CPU 값은 실제 센서를 읽으며, 신호가 없으면 숫자 대신 대시(—)가 표시됩니다.
  5. 전송 중지는 USB 연결을 놓습니다. TRCC로 돌아가기는 전송을 중지하고 기존 TRCC를 엽니다. 중지 직후 숫자가 마지막 값에 머물 수 있습니다.

이 PC에서 확인한 PA120 DIGITAL 84개 LED 숫자 표시 모델 전용입니다. 동영상이나 이미지를 표시하는 LCD 모델 기능은 포함하지 않습니다. 온도 연동 색상은 30°C 미만 청록, 50°C 미만 초록, 70°C 미만 노랑, 85°C 미만 주황, 그 이상 빨강입니다. 디스플레이 색상은 그래픽카드 RGB 색상과 별도로 설정할 수 있습니다.

MSI 그래픽카드 RGB: 장치를 MSI GeForce RTX 4070 Gaming X Trio로 선택하고 단색으로 켜기를 누르세요. 이 모델의 단색 모드는 Direct입니다. Off는 조명을 끄는 효과입니다. 적용 후 약 1.5초간 실제 갱신을 기다립니다. 이 PC에서는 민트색·70% 적용 후 실제 조명 변경을 사용자와 확인했습니다.

처음 실행할 때

  1. 배포 폴더의 FanRgbStudio.exe 또는 바탕화면 선웅 Fan Studio 바로가기를 엽니다. 실행 파일 옆의 DLL·tools 폴더를 함께 보관하세요.
  2. 왼쪽에 드라이버 미설치가 보이면 센서 드라이버 설치를 누릅니다. 함께 들어 있는 공식 PawnIO 2.2.0 설치 프로그램이 열립니다. Windows의 관리자 승인과 설치 완료는 직접 진행하세요.
  3. 설치 후 앱의 관리자로 다시 열기를 누릅니다. Windows 관리자 승인 창에서 직접 승인합니다. 앱을 관리자 권한으로 재시작해야 드라이버를 새로 확인합니다.
  4. CPU 온도와 팬 채널이 표시되는지 확인하세요. 지원되지 않거나 온도를 읽지 못하면 팬 적용 버튼을 사용할 수 없습니다.

이 PC에서 확인한 장치: ASRock B650M PG Lightning, AMD Ryzen 5 9600X, NVIDIA GeForce RTX 4070. 일반 권한에서 GPU 센서 읽기를 확인했습니다. 메인보드 팬의 실제 조절 여부는 드라이버 설치와 관리자 실행 후 확인해야 합니다.

팬 속도 설정

  1. 조절할 팬 채널에 체크합니다. 이름을 모르면 여러 채널을 한 번에 선택하지 말고 연결된 팬을 먼저 확인하세요. AIO/PUMP 등 수랭 펌프 채널은 선택하지 마세요. 이름만으로 팬과 펌프를 완전히 구분할 수 없습니다. 마우스를 채널에 올리면 장치 이름과 센서 ID가 보입니다.
  2. 저소음 / 균형 / 성능 / 수동 중 하나를 고릅니다. 수동을 골랐을 때만 출력 슬라이더가 활성화됩니다.
  3. 팬 설정 적용을 누릅니다. 적용 후 채널의 출력 수치와 실제 소음·회전을 확인하세요. 체크 해제만으로 이미 적용한 제어가 해제되지는 않습니다.
  4. 돌아가려면 기본 제어 복원을 누릅니다. 이 앱이 제어한 채널만 기본 제어로 복원합니다.

팬 제어의 복원 동작과 한계

정상 종료, CPU 온도 신호 상실, 제어 오류 때 이 앱이 잡은 채널에 기본 제어 복원을 요청합니다. 센서 작업은 별도 프로세스에서 실행되며 화면 앱의 응답이 약 10초 끊기면 복원을 시도합니다. 운영체제·드라이버까지 멈추거나 전원이 끊기면 복원 실행을 보장할 수 없습니다. 팬 정지 기능이나 회전수 기반 최저 출력 자동 보정은 없습니다. 다른 팬 제어 프로그램과 동시에 같은 채널을 제어하지 마세요.

RGB 설정

  1. RGB 연결을 누릅니다. 포함된 OpenRGB 1.1 엔진이 실제 장치를 검색합니다. 이때는 검색만 요청하며, 색상 적용 명령을 보내지 않습니다. 이미 실행 중인 로컬 OpenRGB SDK 서버가 있으면 그 서버를 사용합니다.
  2. 감지된 장치와 장치 효과를 선택합니다. 효과 이름은 장치가 제공하는 목록이며 모든 장치에 같은 효과가 있는 것은 아닙니다.
  3. 색상 버튼을 고르거나 #53D9C5처럼 #과 6자리 HEX를 입력합니다. 밝기를 정한 뒤 조명 설정 적용을 누릅니다.
  4. 실제 팬 조명이 바뀌었는지 직접 확인합니다. 원형 그림은 선택한 색의 미리보기이며 실제 하드웨어 상태를 읽어 보여 주는 화면이 아닙니다.

RGB 명령은 해당 컴퓨터의 127.0.0.1:6742에만 연결됩니다. SDK 프로토콜 3은 실제 LED 동작 완료를 확인하는 응답을 제공하지 않으므로 “전송 완료”는 물리적인 조명 변경을 보장하는 문구가 아닙니다. 일부 효과는 색상이나 밝기를 지원하지 않습니다. 자체 밝기 기능이 없는 모드는 지정 색상을 어둡게 해서 밝기를 표현하므로, 무지개처럼 장치가 자체 색상을 생성하는 효과에는 밝기 조절이 반영되지 않을 수 있습니다. 이 앱을 종료해도 RGB 색상·장치 자체 효과는 남을 수 있습니다.

RGB 장치가 안 보이면
  • RGB 지원 여부는 메인보드·USB RGB 허브 모델과 배선에 따라 달라집니다. 모든 RGB 팬을 소프트웨어로 조절할 수 있는 것은 아닙니다.
  • 팬의 회전 전원 선과 조명 선은 별개입니다. 케이스 버튼에만 연결된 허브는 앱에서 보이지 않을 수 있습니다. 메인보드 동기화 모드가 있는 허브는 해당 제품 설명서를 확인하세요.
  • 5V 3핀 ARGB와 12V 4핀 RGB를 혼용하지 마세요. 배선을 확인할 때는 컴퓨터 전원을 끄고 해당 제품 설명서를 따르세요.
  • Polychrome / SignalRGB 등 다른 RGB 프로그램이 같은 제어기를 사용 중인지 확인하세요. 앱은 다른 프로그램을 강제로 종료하지 않습니다.
  • PawnIO 설치 후 관리자로 실행하면 일부 메인보드 RGB 감지에 도움이 됩니다. 그래도 안 보이면 OpenRGB 1.1 지원 목록에서 정확한 컨트롤러를 확인하세요.

시스템 팬 색상 반영 수정

ASRock USB 메인보드에서 구역별 단색을 Direct로 보내면 실제 조명이 갱신되지 않을 수 있어 Static으로 전환합니다. SDK 반영과 실물 변화는 별도입니다. 이번 PC에서는 수정 후 빨강 단독 테스트의 실물 변화를 사용자가 확인했습니다.

실제 LED 색상 보정

RGB 영역에서 실제 LED 색상 보정을 펼칩니다. 노랑·초록이 강하면 노랑·초록 줄이기를 누른 뒤 조명 설정 적용을 누르세요. 초록 성분을 80%로 줄이며 장치별로 저장합니다. 빨강·초록·파랑 슬라이더로 직접 조절하거나 보정 초기화로 모두 100%로 돌릴 수 있습니다. 이 PC의 시스템 팬에는 빨강100/초록70/파랑100% 보정을 저장했고 사용자가 색상 개선을 확인했습니다. 원본 HEX는 유지합니다. LED와 화면의 완전한 색 일치를 보장하지 않습니다.

재부팅 후 그래픽카드 색상 자동 복원

조명 설정 적용을 누르면 색상·밝기·효과·보정값을 장치와 구역별로 저장합니다. 기존 저장 장치도 첫 실행 때 이관합니다. 로그인 후 기존 시작 작업이 앱을 켜고, 장치가 감지되면 설정을 전송합니다. 감지가 늦으면 최대 2분 재시도하고 첫 성공 10초 뒤 한 번 더 보냅니다. 초기 부팅 중 잠시 기본 색이 보일 수 있습니다. 사용자가 새 설정을 적용하면 이전 설정의 재시도를 중단합니다.

온도 구간별 사용자 곡선

  1. 팬 속도 프로필에서 사용자 곡선을 고릅니다.
  2. 표에서 온도(°C)와 팬 출력(%)을 직접 편집합니다. 예: 40°C/35%, 60°C/60%, 80°C/90%. 지점 사이 출력은 부드럽게 이어집니다.
  3. 지점 추가로 온도 구간을 나누고 선택 삭제로 합칠 수 있습니다. 2~12개 지점을 지원합니다.
  4. 조절할 팬 채널을 체크하고 팬 설정 적용을 누릅니다. 적용한 채널별 곡선은 자동 저장되고 다음 실행에 복원됩니다.

온도는 20~85°C, 출력은 30~100%입니다. 온도는 증가하는 순서로 입력하고 높은 온도에서 출력이 낮아지지 않도록 설정합니다. 마지막 85°C/100% 보호 지점은 유지합니다. CPU·GPU 중 가장 높은 온도를 기준으로 동작합니다. 펌프 채널은 선택하지 마세요. 채널마다 다른 곡선을 원하면 각 채널을 따로 선택해 적용합니다.

수동 팬 속도 미세 조절

수동 모드에서 30.0~100.0% 사이 값을 직접 입력하고 Enter를 누릅니다. ±0.1/±1 버튼과 슬라이더 방향키로 미세 조절할 수 있습니다. 선택한 팬에 적용하려면 팬 설정 적용을 누르세요. 소수점도 자동 저장됩니다. 실제 출력은 하드웨어 PWM 단위로 반올림되므로 입력과 측정 출력이 약간 다를 수 있습니다. 85°C 이상 최대 출력 보호는 유지합니다.

설정과 진단

내 설정 저장은 선택한 색상·밝기·효과 이름·팬 프로필·수동 출력을 이 PC에 저장합니다. 적용한 팬의 채널·모드·출력은 fan-profile.json에 자동 저장되고 다음 실행에 자동 복원됩니다. CPU 온도와 장치 일치를 확인한 후 시작합니다. 기본 제어 복원은 저장된 팬 설정도 삭제합니다. 완전히 종료하면 물리 팬은 기본 제어로 돌아가지만 저장값은 유지합니다. 진단 폴더 열기에서 preferences.json, latest-diagnostics.json, studio.log를 확인할 수 있습니다. 데이터는 사용자 폴더의 AppData\Local\SunuongFanStudio에 저장됩니다. 이 PC에는 로그인 15초 뒤 실행하는 시작 작업이 등록돼 있습니다. 클라우드 동기화는 없습니다.

확인한 범위와 한계

관리자 실행으로 CPU 온도·CPU 사용률·메인보드 팬 센서·RTX 4070 온도/사용률을 실제로 읽었습니다. GPU 민트색·70%는 사용자와 실물 변화를 확인했습니다. v1.1.1에서는 초기화 응답과 지속 전송을 추가한 뒤 사용자가 실제 쿨러에 숫자가 보임을 확인했습니다. 최종 실행 파일에서도 PA120 모델 응답과 연결 유지, 실시간 센서 갱신을 확인했습니다. 자동 검사 18개는 팬 곡선·CPU 온도 부재·RGB 통신·PA120 초기화와 모델 구분·숫자 인코딩/USB 보고서/센서 선택·설정 호환성을 포함합니다. 실제 팬 출력 변경과 펌프 구분은 이번 변경에서 검사하지 않았습니다. 다른 PC나 다른 모델의 표시 성공까지 보장하는 것은 아닙니다.
